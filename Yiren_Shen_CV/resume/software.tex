\cvsection{Software}

\begin{cvparagraph}
Most of the following software projects are hosted on my GitHub account: https://github.com/yiren6.
\end{cvparagraph}

\begin{cvitems}
\setlength{\itemsep}{1em} % Adjusts the space between items
\paragraphstyle
\item \texttt{analyze\_svf}, analyze\_svf is an automated program developed in MATLAB for analyzing sooting images and extracting soot volume fraction (SVF) quantitatively. 

\item \texttt{Blasius\_ANN}, Blasius\_ANN is a boundary layer Constitutive Artificial Neural Network (CANN) model solver for self-similar solutions of boundary layer profiles. 

\item \texttt{blade-mesh-builder}, blade-mesh-builder is a tool to discretize fan blades based on their airfoils and build structured mesh for fluid or structural simulations. 

\item \texttt{MF-VortexNet}, MF-VortexNet is a GNN-based field prediction surrogate model that leverages CFD simulations to correct and improve prediction fidelities of vortex lattice method solver for accurate and fast aerodynamic design. 

\item \texttt{SU2\_EGADS}, SU2\_EGADS is an extension to SU2 open-source PDE solver suite that integrates EGADS, a parametric geometry environment, for parametric geometry design and optimization. 







\end{cvitems}
